# <a id="course-links"></a>Course links

| Course | Links | Role |
| --- | --- | --- |
| Stanford CS224N, Spring 2024 — Christopher Manning, *Natural Language Processing with Deep Learning* | [Course](https://web.stanford.edu/class/archive/cs/cs224n/cs224n.1246/) · [Lecture playlist](https://www.youtube.com/playlist?list=PLoROMvodv4rOaMFbaqxPDoLWjDaRAdP9D) | Main course: word vectors, language models, pretraining, post-training, evaluation, reasoning and agents, machine translation, and parsing (chapters 2–3, 5, 9–16). Its four assignments cover word vectors, a neural dependency parser, attention-based translation, and pretraining and fine-tuning a small transformer. |
| Stanford CS336, Spring 2025 — Percy Liang and Tatsunori Hashimoto, *Language Modeling from Scratch* | [Course](https://cs336.stanford.edu/spring2025/) · [Lecture playlist](https://www.youtube.com/playlist?list=PLoROMvodv4rOY23Y0BoGoBGgQ1zmU_MT_) · [Lecture materials](https://github.com/stanford-cs336/spring2025-lectures) · [Spring 2026 recordings](https://www.youtube.com/playlist?list=PLoROMvodv4rMqXOcazWaTUHhq-yembLCV) | Main course: building a language model end to end, from tokenization, architectures, mixture of experts, and resource accounting to scaling laws, inference, evaluation, data, and alignment with reinforcement learning (chapters 1, 4, 6–8, 11–12, 14). Several lectures are executable Python files viewed in the course's trace viewer. Its five assignments build a tokenizer and transformer, systems optimizations, a scaling-law study, a data pipeline, and post-training for mathematical reasoning. |
| CMU 11-711, Fall 2025 — Sean Welleck, *Advanced Natural Language Processing* | [Course page with slides](https://cmu-l3.github.io/anlp-fall2025/) · [Code](https://github.com/cmu-l3/anlp-fall2025-code) | Supplement: in-context learning, fine-tuning, decoding and inference-time algorithms, retrieval, evaluation and experimental design, reinforcement learning for language models, and agents (chapters 5, 8–10, 12–14). The code repository has short notebooks for many lectures. |
